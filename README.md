# Фрактальная геометрия чисел-близнецов: Анализ размерности Хаусдорфа

В этом репозитории содержатся исходный код и экспериментальный фреймворк для анализа распределения **чисел-близнецов** с помощью методов нелинейной динамики, теории хаоса и фрактальной геометрии.

Вместо классических аналитических методов теории чисел («методов сита»), этот проект моделирует Решето Эратосфена как динамический, разрушающий пространство геометрический процесс. Мы наглядно доказываем, что простые числа ведут себя как самоподобная фрактальная структура, удивительно похожая на знаменитую **Канторову пыль**.

## 🌌 Ключевой концепт: «Решето как фрактал»

В чистой математике простые числа ищут путем последовательного вычеркивания составных чисел (каждого 2-го, каждого 3-го, каждого 5-го и т.д.). Этот проект визуализирует этот процесс, сворачивая числовую ось в **полярную спираль** ($\theta = r = n$).

При таком подходе хаотичное на первый взгляд распределение простых чисел мгновенно подчиняется строгой геометрии и выстраивается в четкие радиальные рукава симметрии, образуя настоящую «числовую галактику».

Наша гипотеза утверждает: остаточное пространство **чисел-близнецов** (пар простых чисел с жестким зазором ровно в 2 единицы) обладает фрактальной плотностью, которая физически не может исчезнуть на бесконечности. Самоподобие числовой оси заставляет эти микро-зазоры дублироваться на каждом новом масштабе вселенной чисел.

## 📊 Главные открытия и масштабы

* **Базовый масштаб (50 000 чисел):** Вычисленная плотность фрактала стабилизируется в районе $D \approx 0.61$.
* **Экстремальный масштаб (1 000 000 000 чисел):** Благодаря оптимизации NumPy, симулятор успешно преодолел барьер в **1 миллиард чисел**, найдя ровно **3 424 506 пар близнецов**. На этом масштабе глобальная стабильная размерность Хаусдорфа уплотняется до **$D \approx 0.9702$**, стремясь к монолиту.
* В теории хаоса любой фрактал с размерностью строго больше нуля обладает **бесконечной структурой**. Геометрия числового пространства просто не позволит парам-близнецам закончиться на бесконечности.

## 📁 Структура репозитория

Внутри проекта находятся три специализированных инструмента:
1. `twin_primes_fractal.py` — базовый симулятор фрактальной спирали до 50 000 чисел с расчетом размерности [1.1].
2. `twin_primes_animation.py` — интерактивный симулятор, показывающий эволюцию числовой галактики и динамический пересчет коэффициента $D$ в реальном времени (от 2 000 до 100 000 чисел).
3. `twin_primes_god_mode.py` — супер-оптимизированный векторный движок на NumPy для ультра-скоростного расчета экстремальных масштабов до 1 миллиарда чисел с логарифмическим сжатием радиуса.

## 🚀 Быстрый запуск

### Системные требования

Для запуска симуляторов вам понадобятся Python 3.x и библиотеки `numpy` и `matplotlib`.

```bash
pip install numpy matplotlib
```

### Запуск интерактивной анимации

Клонируйте этот репозиторий и запустите скрипт живой эволюции фрактала:

```bash
git clone https://github.com
cd twin-primes-fractal
python twin_primes_animation.py
```
